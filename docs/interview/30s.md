# 30 秒口播

> 我做了一个 Amazon 商品情报 Agent。它读取 `电商分析.xlsx` 里的 4 个 ASIN，低频采集 Amazon 公开商品页，抽出价格、销量、星级、评价、图片和五点描述；原始 HTML 缓存可以离线 replay，SQLite 保证同一天重跑幂等，最后把结果回写 Excel。
>
> 它不是一个“让 LLM 随便总结网页”的项目。价格和销量由确定性选择器负责，LLM 只做趋势解释；所有数字必须能回到快照，不通过 grounding 就降级。真实页面评估 44/44，45 个测试，真实 LLM grounding 8/8（1 条降级），失败缺口和第三方卖家都会明确记录。

## 关键词

- 确定性抽数 + LLM 解释
- replay / live 双路径
- 缺口不编造
- 同一天重跑只更新
- Excel 是交付物
- 真实页面 + hash 证据
